# Recoil Bloom 需求文档

## 1. Overview

一款以 CSS 元素弹道、后坐力和边缘飞溅为核心的自定节奏视觉游戏：玩家按住喷射并借后坐力漂移，依次在画布四边留下印记。

## 2. Visual Design

产品必须保留 David Aerne 原作的深炭灰全屏画布、白边圆形喷射器、LCH 连续变色弹丸、边缘爆裂与停驻的 CSS 粒子。界面只在左上显示标题、右上显示 `0/4` 进度，四边各有一个细线定位印记；最终状态继续展示玩家产生的飞溅画面。目标为竖屏 `390×844`、窄屏 `320×568` 与桌面浏览器。

## 3. Game Mechanics

- 喷射器从视口中心生成，速度初始为 0，每帧速度乘 `0.98`。
- 按住时每 `54ms` 发射一枚弹丸；弹丸速度为 `25px/帧`，每次发射向反方向施加 `1.55` 后坐力。
- 弹丸触碰任一视口边缘时生成 `10–29` 个粒子；粒子初速度 `2–5px/帧`，生命为 `10–49` 帧，结束后留在画布上。
- 玩家距停驻粒子小于 `50px` 时擦除该粒子，保留原作“穿过墨点会清除”的行为。
- 上、右、下、左四边各有一个完成条件；该边首次被弹丸命中即永久点亮。
- 四边全部点亮后停止继续发射，但保留喷射器、飞溅和最后构图；重播会清空粒子、随机新色相并回到中心。

## 4. Controls

- 单指或鼠标移动：喷射器实时朝向指针。
- `pointerdown`：同帧发射并开始连续喷射。
- `pointerup / pointercancel`：停止喷射。
- 完成后的 44×44 SVG 重播按钮：清空并重新开始。

## 5. Win / Lose Conditions

没有失败或倒计时。上、右、下、左四边都至少命中一次即完成；完成状态显示“画面已签署”，保留最终飞溅画面并提供重播。

## 6. Sound Effects

首次触摸后恢复 Web Audio：连续射击使用限频至最短 `68ms` 间隔的短促低频反冲脉冲；四边首次命中按方向播放不同音高的双层色彩音；四边完成播放四音上行和弦。四边首次命中使用 `16ms` 轻震，完成使用 `24ms / 40ms 间隔 / 48ms` 两段触觉反馈。`?mute=1` 或浏览器不支持音频时静默降级。
