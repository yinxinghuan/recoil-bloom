# Recoil Bloom 需求文档

## 1. Overview

一款以 CSS 元素弹道、可恢复后坐力和边缘飞溅为核心的自定节奏瞄准游戏：玩家用短喷命中依次点亮的六个边缘花瓣，同时借中心弹性牵引重新取得空间。

## 2. Visual Design

产品必须保留 David Aerne 原作的深炭灰全屏画布、白边圆形喷射器、LCH 连续变色弹丸、边缘爆裂与停驻的 CSS 粒子。界面只在左上显示标题、右上显示 `0/6` 进度；场上一次只突出一个边缘花瓣，并用一条低对比弹性线解释喷射器会回到中心。最终状态继续展示玩家产生的飞溅画面。目标为竖屏 `390×844`、窄屏 `320×568` 与桌面浏览器。

## 3. Game Mechanics

- 喷射器从视口中心生成，速度初始为 0。按住喷射时每帧受到指向中心的 `0.0016 × 位移` 弹力并乘 `0.94` 阻尼；松手后弹力提高至 `0.0048 × 位移`、阻尼提高至 `0.88`，使玩家约在 `0.8–1.4s` 内明显回中。
- 按住时每 `82ms` 发射一枚弹丸；弹丸速度为 `25px/帧`，每次发射向反方向施加 `0.82` 后坐力。玩家速度上限为 `7px/帧`，距四边 `24px` 处以 `0.58` 系数反弹。
- 弹丸触碰任一视口边缘时生成 `10–29` 个粒子；粒子初速度 `2–5px/帧`，生命为 `10–49` 帧，结束后留在画布上。
- 玩家距停驻粒子小于 `50px` 时擦除该粒子，保留原作“穿过墨点会清除”的行为。
- 每局生成六个边缘花瓣：前四个覆盖上、右、下、左各一次并随机排序，后两个随机选择且不会连续重复；上下目标沿横轴限制在 `22%–78%`，左右目标沿纵轴限制在 `32%–72%`，避开标题、平台控件和底部提示。
- 场上一次只激活一个花瓣。弹丸必须在对应边、距离花瓣中心不超过 `58px` 时才推进；打偏仍产生原作飞溅，但不增加进度。
- 命中后当前花瓣确认并在 `180ms` 内切换到下一个；六个全部命中后停止继续发射，但保留喷射器、飞溅和最后构图。重播会清空粒子、生成新目标顺序、随机新色相并回到中心。

## 4. Controls

- 单指拖动或鼠标移动：喷射器实时朝向指针。
- `pointerdown`：同帧发射并开始连续喷射；推荐用短喷控制反冲。
- `pointerup / pointercancel`：停止喷射。
- 完成后的 44×44 SVG 重播按钮：清空并重新开始。

## 5. Win / Lose Conditions

没有失败或倒计时。依次命中六个发光边缘花瓣即完成；完成状态显示“花迹完成”，保留最终飞溅画面并提供重播。打偏只留下视觉痕迹，玩家始终可以松手回中后继续。

## 6. Sound Effects

首次触摸后恢复 Web Audio：连续射击使用限频至最短 `76ms` 间隔的短促低频反冲脉冲；打偏播放 `92Hz→62Hz`、`70ms` 的低音提示；花瓣命中按方向播放不同音高的双层色彩音；六瓣完成播放四音上行和弦。花瓣命中使用 `16ms` 轻震，完成使用 `24ms / 40ms 间隔 / 48ms` 两段触觉反馈。`?mute=1` 或浏览器不支持音频时静默降级。
