# Recoil Bloom

> Adapted from **“css splatters (click for craze)”** by **David Aerne (meodai)**.  
> Original demo/source: https://codepen.io/meodai/pen/WNPKNzv  
> Retrieved 2026-07-27. Public CodePen source licensed under the MIT License.

Recoil Bloom preserves the original CSS projectile, recoil, collision, and persistent spatter engine, then adds a self-paced four-edge closure for touch screens.

## Development

```bash
npm install
npm run dev
npm run build
```

The product route is the default entry; the preserved mechanism is documented in `upstream/SOURCE.md`.
